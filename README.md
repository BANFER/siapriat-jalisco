# SIAPRIAT · Insulini — demostración

Prototipo del equipo **BAN INDUSTRIES** (Universidad Tecnológica de Altamira) para el **Hackathon Jalisco 2026, Reto 02: Salud y Bienestar**.
Seguimiento de alimentación y horarios para personas con diabetes en la región Wixárika de Jalisco, con vínculo opcional al personal de salud.

| Dispositivo | Cómo probarla |
|---|---|
| Cualquier navegador (iPhone, Android, computadora) | **https://banfer.github.io/siapriat-jalisco/** |
| Android 7 o más reciente | Descarga `SIAPRIAT-android.apk` en [Releases](https://github.com/BANFER/siapriat-jalisco/releases/latest) |
| Mac con Xcode (simulador de iPhone) | Descarga `SIAPRIAT-ios-simulador.zip` en [Releases](https://github.com/BANFER/siapriat-jalisco/releases/latest) |

Este repositorio solo contiene la **versión web compilada** y los instalables. Todo es **modo demostración**: personas y registros ficticios;
lo que escribas se queda en tu navegador o teléfono. No diagnostica ni recomienda tratamientos y no está validado para uso clínico.
